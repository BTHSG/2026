Hướng Dẫn Cấu Hình Firebase Rules & CORS

1 Cloud Firestore Security Rules

Vào Firebase Console > Firestore Database > Tab Rules, dán quy tắc sau để cho phép học sinh đọc danh sách và gửi bài mới (nhưng không được xóa/sửa): 

rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /submissions/{submissionId} {
      // Cho phép học sinh xem và nộp bài
      allow read, create: if true;
      // Ngăn chặn xóa hoặc sửa đổi dữ liệu đã nộp
      allow update, delete: if false;
    }
  }
}
2 Firebase Storage Security Rules

Vào Firebase Console > Storage > Tab Rules, dán quy tắc sau (giới hạn tệp mã nguồn dưới 10MB): 

rules_version = '2';
service firebase.storage {
  match /b/{bucket}/o {
    match /submissions/{allPaths=**} {
      // Cho phép tải xuống và tải lên nếu tệp < 10MB
      allow read, create: if request.resource.size < 10 * 1024 * 1024;
      allow update, delete: if false;
    }
  }
}
3 Khắc phục lỗi CORS khi Upload từ Trình duyệt

Nếu gặp lỗi "Access-Control-Allow-Origin" khi tải file lên Storage, hãy mở Google Cloud Shell hoặc terminal và áp dụng cấu hình CORS:

Tạo file cors.json:
[
  {
    "origin": ["*"],
    "method": ["GET", "POST", "PUT", "DELETE", "HEAD"],
    "maxAgeSeconds": 3600,
    "responseHeader": ["Content-Type", "Access-Control-Allow-Origin", "x-goog-resumable"]
  }
]
Chạy lệnh sau (thay your-bucket bằng tên bucket của bạn):
gsutil cors set cors.json gs://<your-project-id>.appspot.com
